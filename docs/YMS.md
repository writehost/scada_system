# YMS — отдельное приложение

Живой адрес: https://yms.scadasystem.io

Это не часть процесса WMS и не GSMT.

| | |
|---|---|
| Каталог | `/opt/scadatable-yms` |
| Служба | `scadatable-yms` |
| Порт | `127.0.0.1:3014` |
| Nginx | `/etc/nginx/sites-available/yms.scadasystem.io` |
| Код | `yms-app/` в этом репозитории |

WMS остаётся на `scadatable-wms-ui` и порту 3004. GSMT на порту 3000. Их каталоги при деплое YMS не копируются и службы не перезапускаются.

Вход — тот же логин и пароль пользователя WMS (`wms_users`). Сессия только на домене `yms.scadasystem.io`.

База та же `wms_edge`. Таблицы `yms_*` добавляются скриптом `yms-app/scripts/ensure-plain.mjs`, остатки склада не меняются.

Локальная сборка:

```bash
cd yms-app
npm install
npm run build
```

На сервер уходит только `.next/standalone` вместе со `.next/static`. `PORT` в скрипте запуска принудительно 3014, чтобы значение из общего env-файла WMS не заняло порт 3004.


Страницы: `/` диспетчер, `/gate` КПП. API: `/api/yms/*`.

## Что делает MVP

- Заявка на визит и справочник машин (не путать с карщиками склада ГП).
- Очередь со строгой сменой статусов.
- Доки и стоянки, атомарное назначение, один визит на док.
- Диспетчерская: очередь, план, доки, журнал.
- КПП: поиск по номеру, въезд, выезд, внеплановый визит.
- Связь с заказом отгрузки или отбора WMS только чтением. Остатки YMS не пишет.
- Исходящую погрузку нельзя закрыть, пока склад не подтвердил количество, либо явно зафиксировано расхождение.

## Чего нет в этом срезе

Календарь окон, портал водителя, WebSocket, SMS, распознавание номеров, шлагбаумы, кросс-док как складской процесс.

## Роли

Существующие: `admin` и `warehouse_manager` — полный доступ, `warehouse_operator` — чтение и подтверждение расхождения, `auditor` — чтение.

Дополнительно, если строки есть в `wms_roles`: `yms_dispatcher`, `yms_guard`, `yms_logist`, `yms_warehouse`.

## Погрузка, водители, карта

Подтверждение отгрузки идёт по кодам палет `wms_load_units` и сканам `wms_tasks.task_payload.shipScans`. Если кодов в заказе нет, YMS не отмечает палету погруженной. Кнопка завершения у диспетчера без права склада не закрывает визит.

Водители хранятся отдельно от визита. Кабинет водителя — ссылка `/d/…` только на свой рейс. Вызов к доку пишется как отправленный на табло; доставка SMS не подтверждается, пока нет канала.

Погрузчики читаются из файла флота карщиков WMS. Если файла нет, список пуст и задание не создаётся. На карте погрузчик стоит в зоне назначенного дока с подписью «зона дока»: координат в флоте нет.

Тягач и полуприцеп рисуются по подтверждённой точке (КПП, стоянка, док). Маршрут строится по проездам и не проходит сквозь здания. Ложного движения нет.

Эти изменения собраны в `yms-app` и на `yms.scadasystem.io` ещё не выкладывались.

## Обновление на заводе

Собирать `yms-app` отдельно и выкладывать standalone в `/opt/scadatable-yms`. Службу `scadatable-wms-ui` и каталог Frontend не останавливать и не перезаписывать. GSMT не трогать.
