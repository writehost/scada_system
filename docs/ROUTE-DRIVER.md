# SCADA System Route — инструкция водителя погрузчика

Планшет на погрузчике показывает один экран: **куда ехать, что забрать, куда поставить и что нажать дальше**.

## Начало смены

1. Откройте `yms.scadasystem.io/route`, войдите своим логином WMS (или через SCADA ID).
2. Нажмите на свой погрузчик («Кара №1»). Если он занят другим водителем — обратитесь к диспетчеру.
3. Вверху экрана видно: погрузчик, ваше имя, смена, **связь** и **позиция**.

| Значок | Что значит |
|---|---|
| ● На связи / ✕ Нет соединения | связь с сервером |
| ⌖ Позиция по меткам | позиция по меткам на потолке, точная |
| ⌖ Позиция неточная | метки временно не видны — показана последняя известная точка |
| ⌖ Позиция не определена | меток нет дольше 3 секунд — ориентируйтесь по адресам |
| ✋ Ручная позиция | позицию задал диспетчер, это не измерение |

## Задание

Экран: **сверху** — статус, **посередине** — карта, **внизу** — что сделать сейчас и большая кнопка.

1. **Новое задание** → «Принять задание» (или «Отказаться» с причиной).
2. **«К месту получения — …»**: едьте по зелёной линии к синей метке ↑. По приезде нажмите «Я на месте» или сразу сканируйте палету.
3. **«Отсканируйте палету»**: наведите сканер на этикетку SSCC.
   - ✔ зелёная строка — палета та: продукция, партия, код. Нажмите **«Подтвердить погрузку»**.
   - ✕ **«Неверная палета»** — показано, какая ожидается и какую вы отсканировали. Палету не берите, найдите нужную. Задание по факту скана не меняется.
4. **«Доставьте палету в FG-A-32»**: едьте по линии к оранжевой метке ↓, ряд назначения обведён.
5. **«Подтвердите адрес FG-A-32»**: отсканируйте QR/DataMatrix ячейки.
   - ✕ «Неверный адрес» — вы не у того ряда.
   - Если адрес занят или запрещён правилами — появится кнопка **«Другой адрес»**: WMS назначит новый, маршрут перестроится.
6. Поставьте палету и нажмите **«Подтвердить постановку»**. Задание завершится **только когда WMS подтвердит перемещение**.
7. Следующее подходящее задание появится сразу — снова «Принять задание».

Сканер работает всегда, отдельное окно открывать не нужно. Камера планшета — кнопка «Сканировать палету/адрес». Ручной ввод («Вручную») — только если разрешено вашей роли, с обязательной причиной.

## Если что-то не так — кнопка «Проблема»

Выберите причину: палеты нет на месте, на месте другая палета, палета повреждена, адрес занят, не проехать, неисправен погрузчик, остановить задание, позвать диспетчера. Случай записывается в журнал, диспетчер видит его сразу.

- **«Остановлено: …»** — задание ждёт решения диспетчера. Нажмите «Сообщить диспетчеру», если нужно добавить информацию.
- **«Безопасный маршрут не найден»** — проезд закрыт. Не объезжайте через закрытые участки, дождитесь диспетчера.
- **«Задание отменено»** — экран обновится сам, старое задание подтвердить нельзя.
- **«Пауза»** — приостановить задание (перерыв, пропустить пешеходов). «Продолжить» — вернуться.

## Нет соединения

Сверху красная надпись «Нет соединения». Карта и последнее задание остаются на экране, но **подтверждения не отправляются** и новые задания не приходят. Когда связь вернётся, нажмите кнопку ещё раз — повтор безопасен, двойного перемещения не будет.

## Конец смены

Без задания внизу — «Закончить смену». Если вы пересели на другой погрузчик, просто выберите его: прежняя сессия закроется, незавершённые задания вернутся диспетчеру.

**Помните:** навигатор подсказывает маршрут, но не видит людей и препятствия. Правила безопасного движения по складу — прежде всего.
