# Android TSD Smoke Test

Папка приложения: `web/interface/android/app`

## 1) Подготовка backend

1. Запустить PostgreSQL и применить миграции:
   - `.\migrate-db.ps1`
2. Запустить Next backend (`/api/wms/*`):
   - `.\start-web.ps1`
3. Убедиться, что backend доступен с ТСД:
   - `http://<LAN-IP>:3001/api/wms/health`

## 2) Настройка Android приложения

На главном экране приложения заполнить:

- `Base URL`: `http://<LAN-IP>:3001/`
- `Site code`: `DEFAULT`
- `Device UID`: уникальный ID терминала (например `TSD-A1`)
- `Device name`: человекочитаемое имя
- `Operator userId` (опционально): ID оператора в `wms_users`

Нажать `Сохранить и переподключить`.

## 3) Сценарный прогон

1. **register + profile**
   - после сохранения настроек не должно быть ошибки подключения;
   - в карточке статуса показываются оператор/ТСД.
2. **получение задач**
   - открыть экран `Задачи`;
   - убедиться, что список заполняется из `/api/wms/devices/tasks`.
3. **жизненный цикл**
   - на задаче нажать `Взять` → `Старт` → `Готово`;
   - при необходимости проверить `Исключить`.
4. **скан / lookup**
   - открыть `Скан`;
   - отсканировать код; проверить поиск через `/api/wms/lookup`.
5. **offline / outbox**
   - отключить сеть на ТСД;
   - выполнить действие по задаче (оно должно уйти в outbox);
   - включить сеть и нажать `Обновить` на экране задач;
   - убедиться, что действие отправилось и outbox очистился.

## 4) Наблюдаемость

- В UI ошибка сети/сервера должна быть видна оператору.
- Для dev-анализа проверять логи backend (`start-web.ps1`) и Android logcat.
